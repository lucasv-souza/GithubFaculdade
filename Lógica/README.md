# Lógica de Programação

Esta pasta contém exercícios de lógica de programação desenvolvidos em linguagem C, abordando estruturas como:

- Condicionais (if, else)
- Laços de repetição (while, for)
- Operadores lógicos e aritméticos
- Resolução de problemas básicos

Todos os arquivos foram produzidos durante as aulas da disciplina de Lógica de Programação no curso de Ciência da Computação.
