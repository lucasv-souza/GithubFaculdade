# Banco de Dados

Esta pasta reúne atividades realizadas na disciplina de Banco de Dados, com foco em **modelagem de dados**.

Foram utilizadas as ferramentas:
- **brModelo** – para criação de diagramas Entidade-Relacionamento (ER);
- **DBDesigner** – para modelagem visual e geração de diagramas relacionais.

As atividades incluem:
- Criação de modelos conceituais;
- Transformação em modelos lógicos;
- Normalização de dados;
- Análise de relacionamentos e integridade referencial.

Os arquivos estão organizados por aula ou atividade.
